# This is a modified fork

Upstream: **[sspanak/tt9](https://github.com/sspanak/tt9)** — everything here is that project's
work, under the Apache License 2.0. This fork exists only to adapt the keyboard to the **Megalife
B2** (codename `g36`), a kosher/filtered candybar phone with a physical T9 keypad, where tt9 is the
system keyboard and the only way to type letters on the keys at all.

Base: **v64.0**.

## Files changed, as Apache-2.0 §4(b) requires

| file | change |
|---|---|
| `app/src/main/AndroidManifest.xml` | removed the `MAIN`/`LAUNCHER` intent-filter from `PreferencesActivity`, so the keyboard has no home-screen icon. `android:exported` stays `true` — the platform still opens that screen explicitly, as the IME's `settingsActivity` |
| `app/languages/definitions/` | reduced to the five languages this product ships: English, Hebrew, Yiddish, Spanish, French. The other 49 removed, with their dictionary sources and n-grams |
| `downloads/` | removed. It is generated output, and it is upstream's publishing directory, not ours |
| `app/version-tools.gradle` | `versionCode` carries a fixed offset, so a Megalife build outranks the build already installed on the handsets |
| `app/src/main/java/…/ui/StatusIcon.java` | regenerated by the build's own `updateStatusIcons` task after the language change |
| `app/src/main/res/values-ji/strings.xml` | **new** — a Yiddish interface, which upstream does not have |

## What is deliberately unchanged

`LICENSE.txt` is upstream's, untouched. The per-dictionary licence notes in
[`docs/dictionaries`](docs/dictionaries) are kept in full — including all five that this fork still
ships. The in-app attribution to Dimo Karaivanov and the project's contributors is preserved, and it
is translated rather than dropped in the new Yiddish resources.

## Two things to know before reusing this

- **Trademark.** Apache-2.0 grants no rights in names or logos (§6). This fork keeps upstream's
  application id, app name and icon because it is built for one ROM and is not published to any
  store. Anything else needs upstream's say-so, not this licence.
- **Signing.** This repository is public. The Megalife platform signing key must never be committed
  to it, and no workflow here may reference one. Platform-signing is done outside this repository,
  on the built artifact.

## The Yiddish resources

Written for this fork, in Hasidic orthography without YIVO diacritics. That follows the `ji-utf8`
word list this keyboard ships beside it: not one of its 138,439 entries carries a diacritic, its
vocabulary is Haredi, and [its own source note](docs/dictionaries/jiWordlistReadme.txt) points at a
Haredi forum. A YIVO interface over that word list would have read as two languages on one screen.
